### [DB] Key

---

> Key란? : 검색, 정렬시 Tuple을 구분할 수 있는 기준이 되는 Attribute.

<br>

#### 1. Candidate Key (후보키)

> Tuple을 유일하게 식별하기 위해 사용하는 속성들의 부분 집합. (기본키로 사용할 수 있는 속성들)

2가지 조건 만족

* 유일성 : Key로 하나의 Tuple을 유일하게 식별할 수 있음
* 최소성 : 유일성을 유지하는 데 필요한 속성만 포함함. 후보키의 속성을 하나라도 빼면 더 이상 Tuple을 유일하게 식별할 수 없어야 함

예를 들어 학생 릴레이션에서 `학번`이 각 학생을 유일하게 구분한다고 하자. 이때 `{학번}`은 유일하고, 속성을 더 뺄 수 없으므로 후보키다. `{학번, 이름}`도 학생을 유일하게 식별하지만 `이름`을 빼도 `{학번}`만으로 식별할 수 있다. 따라서 최소성을 만족하지 않아 후보키가 아니라 슈퍼키다.

즉, 최소성은 속성의 개수가 적다는 뜻이 아니라, **포함된 각 속성이 식별에 실제로 필요한지**를 확인하는 조건이다.

<br>

#### 2. Primary Key (기본키)

> 후보키 중 선택한 Main Key

특징 

* Null 값을 가질 수 없음
* 동일한 값이 중복될 수 없음

<br>

#### 3. Alternate Key (대체키)

> 후보키 중 기본키를 제외한 나머지 키 = 보조키

<br>

#### 4. Super Key (슈퍼키)

> 유일성은 만족하지만, 최소성은 만족하지 못하는 키

<br>

#### 5. Foreign Key (외래키)

> 다른 릴레이션의 기본키를 그대로 참조하는 속성의 집합

<br>
